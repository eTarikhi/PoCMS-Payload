# Amir vTarikhi Live Resume with Next.js

This project is a live resume website for Amir v.Tarikhi, showcasing his professional experience, skills, and projects. The website is built using Next.js, React, and various other modern web development technologies.

## Live Demo

[Live Demo](https://vtarikhi.com)


## Features

- **Responsive Design**: The website is fully responsive and works seamlessly on all devices.
- **Dynamic Content**: Sections like projects and services are dynamically rendered using React components.
- **Smooth Animations**: Utilizes Framer Motion for smooth transitions and animations.
- **SEO Optimized**: Meta tags and descriptions are included for better search engine optimization.
- **Interactive Elements**: Includes interactive elements like image hover effects and smooth scrolling.
- **Performance Optimized**: Code splitting and lazy loading are implemented to enhance the performance of the website.
- **Multi-Language Support**: The website supports multiple languages, allowing users to switch between different languages.
  
## Technologies Used

- **Next.js**: A React framework for server-side rendering and static site generation.
- **React**: A JavaScript library for building user interfaces.
- **Framer Motion**: A library for animations and transitions.
- **Bootstrap**: A CSS framework for responsive design.
- **FontAwesome**: Icon library for adding vector icons and social logos.

## Getting Started

To run this application locally, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/your-username/eTarikhi.com-with-Next.git
    cd eTarikhi.com-with-Next
    ```

2. Install dependencies:
    ```sh
    npm install
    ```

3. Run the development server:
    ```sh
    npm run dev
    ```

4. Open your browser and navigate to `http://localhost:3000` to see the application in action.

## Usage

To use this project, follow these steps:

1. **Navigate the Website**: Browse through different sections like About, Projects, Services, and Contact.
2. **View Projects**: Click on individual projects to see detailed descriptions and links to live demos or repositories.
3. **Contact**: Use the contact form to get in touch with Amir v.Tarikhi.

## Project Structure

- **components/**: Contains React components used throughout the project.
- **pages/**: Contains Next.js pages.
- **styles/**: Contains CSS files for styling the application.
- **public/**: Contains static assets like images and fonts.
